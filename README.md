# 8-Week-SQL-Challenge
This repository showcases my solutions to the [#8WeekChallenge](https://8weeksqlchallenge.com), a platform featuring eight SQL query challenges. Each case study comprises multiple questions across diverse databases.

The repository is organised into dedicated directories for each case study. Each directory contains a Markdown file detailing the questions, the SQL queries, and the resulting tables, accompanied by concise explanations of the code and the analytical outcomes.
